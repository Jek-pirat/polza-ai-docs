Версия 2 отличается от [`GET /v1/balance`](/api-reference/other/balance) семантикой поля `amount`: здесь это всегда полный баланс организации (кошелёк), а сколько именно можно потратить — отдельное поле `available`. Используйте v2 в новом коде.

## Примеры

<CodeGroup>
```bash cURL
curl "https://polza.ai/api/v2/balance" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    'https://polza.ai/api/v2/balance',
    headers={'Authorization': 'Bearer YOUR_API_KEY'}
)

data = response.json()
print(f"Баланс: {data['amount']} руб., доступно: {data['available']} руб.")
```

```javascript JavaScript
const response = await fetch('https://polza.ai/api/v2/balance', {
  headers: { 'Authorization': 'Bearer YOUR_API_KEY' }
});

const data = await response.json();
console.log(`Баланс: ${data.amount} руб., доступно: ${data.available} руб.`);
```
</CodeGroup>

## Ответ (200)

```json
{
  "amount": "1234.56000000",
  "available": "1200.06000000",
  "reservedAmount": "12.50000000",
  "spentAmount": "845.30000000",
  "updatedAt": "2026-04-30T12:00:00.000Z"
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `amount` | string | Баланс организации в рублях (кошелёк). Всегда полный остаток, без учёта лимитов |
| `available` | string | Доступно к трате: остаток за вычетом резерва под выполняющиеся запросы, не больше остатков лимитов расходов ключа и участника |
| `reservedAmount` | string | Зарезервировано под выполняющиеся запросы. Не возвращается, если у участника, на которого выпущен ключ, задан личный лимит расходов |
| `spentAmount` | string | Потрачено организацией за всё время. Не возвращается при личном лимите участника |
| `updatedAt` | string | Время последнего обновления баланса (ISO 8601) |

Все суммы — строки с восемью знаками после точки. Для проверки «хватит ли денег на запрос» ориентируйтесь на `available`: во время выполняющихся запросов оно меньше `amount` на сумму резерва и снова сравнивается с ним после завершения.

<Note>
Ответ кэшируется на 1 секунду. Пополнить баланс можно в [консоли](https://polza.ai/dashboard) через банковскую карту, СБП или счёт для юридических лиц.
</Note>
