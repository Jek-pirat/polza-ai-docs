## Примеры

<CodeGroup>
```bash cURL
curl "https://polza.ai/api/v1/balance" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    'https://polza.ai/api/v1/balance',
    headers={'Authorization': 'Bearer YOUR_API_KEY'}
)

data = response.json()
print(f"Баланс: {data['amount']} руб.")
```

```javascript JavaScript
const response = await fetch('https://polza.ai/api/v1/balance', {
  headers: { 'Authorization': 'Bearer YOUR_API_KEY' }
});

const data = await response.json();
console.log(`Баланс: ${data.amount} руб.`);
```
</CodeGroup>

## Ответ (200)

```json
{
  "amount": "1234.56000000",
  "available": "1200.06000000",
  "reservedAmount": "12.50000000",
  "spentAmount": "845.30000000",
  "updatedAt": "2026-04-30T12:00:00.000Z"
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `amount` | string | Баланс организации в рублях. Если ключ выпущен участником с личным лимитом расходов — остаток этого лимита |
| `available` | string | Доступно к трате: остаток за вычетом резерва под выполняющиеся запросы и с учётом лимитов ключа и участника |
| `reservedAmount` | string | Зарезервировано под выполняющиеся запросы. Не возвращается при личном лимите участника |
| `spentAmount` | string | Потрачено организацией за всё время. Не возвращается при личном лимите участника |
| `updatedAt` | string | Время последнего обновления баланса (ISO 8601) |

<Warning>
В v1 поле `amount` для ключа участника с личным лимитом подменяется остатком лимита. В новом коде используйте [`GET /v2/balance`](/api-reference/other/balance-v2): там `amount` — всегда баланс организации, а доступная сумма — `available`.
</Warning>

## Мониторинг баланса

```python
import requests
import time

def check_balance(api_key, min_balance=100):
    response = requests.get(
        'https://polza.ai/api/v1/balance',
        headers={'Authorization': f'Bearer {api_key}'}
    )

    data = response.json()
    balance = float(data['amount'])

    if balance < min_balance:
        print(f"Внимание! Баланс низкий: {balance} руб.")

    return balance

# Проверка каждый час
while True:
    balance = check_balance('YOUR_API_KEY')
    print(f"Текущий баланс: {balance} руб.")
    time.sleep(3600)
```

<Note>
Пополнить баланс можно в [консоли](https://polza.ai/dashboard) через банковскую карту, СБП или счёт для юридических лиц.
</Note>
