Suno Mashup — инструмент Suno для создания нового трека на основе двух исходных песен. На вход подаются ссылки на два аудиофайла, на выходе — мэшап с переработанным текстом и музыкальным сочетанием исходных композиций.

<Note>
Полная документация API: [Генерация медиа](/api-reference/media/create)
</Note>

## Обзор

| Характеристика | Значение |
|----------------|----------|
| ID модели | `suno/mashup` |
| Эндпоинт | `/api/v1/media` |
| Max prompt | 500 символов (обычный режим) / 5 000 символов (custom mode) |
| Max style | 1 000 символов |
| Max title | 80 символов |
| Количество исходных треков | Ровно 2 (по `uploadUrlList`) |
| Версии | V6 (по умолчанию), V6_MINI, V6_WILD |

## Параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `model` | string | Да | `suno/mashup` |
| `uploadUrlList` | string[] | Да | Ровно 2 публичные URL-ссылки на аудио для смешивания |
| `prompt` | string | Да | Описание трека или lyrics. До 500 символов в обычном режиме, до 5 000 — в custom mode |
| `customMode` | boolean | Нет | Расширенный режим с собственным текстом песни. По умолчанию `false` |
| `style` | string | Нет | Жанр/стиль музыки, до 1 000 символов. Обязателен при использовании custom mode |
| `title` | string | Нет | Название трека, до 80 символов. Обязателен при использовании custom mode |
| `version` | string | Нет | Версия модели: `V6` (по умолчанию), `V6_MINI`, `V6_WILD` |

## Советы и лучшие практики

<AccordionGroup>
  <Accordion title="Доступность ссылок" icon="link">
    Suno должен иметь возможность скачать оба файла по переданным URL. Размещайте аудио на хостинге с публичным доступом и стабильным скачиванием (S3, собственный CDN, публичный bucket). Закрытые или требующие авторизации ссылки приведут к ошибке генерации.
  </Accordion>
  <Accordion title="Конкретный промпт" icon="bullseye">
    Описывайте желаемое настроение, жанр и структуру: «Энергичный поп-рок мэшап с ярким припевом». В custom mode используйте теги `[Verse]`, `[Chorus]`, `[Bridge]`, `[Outro]` для структурирования текста.
  </Accordion>
  <Accordion title="Custom Mode для контроля" icon="sliders">
    Если нужен свой текст, конкретный стиль и название трека — включайте `customMode: true` и передавайте `style`, `title` и расширенный `prompt`. Без custom mode модель сама сформирует текст и подберёт стиль на основе исходных треков.
  </Accordion>
  <Accordion title="Выбор версии модели" icon="code-branch">
    V6 — флагман по умолчанию. V6_MINI — быстрее и дешевле для экспериментов. V6_WILD — даёт более нестандартные сочетания, подходит для творческих поисков.
  </Accordion>
</AccordionGroup>

## Асинхронная генерация

Генерация мэшапа — асинхронный процесс. После отправки запроса вы получите `id`, который нужно использовать для проверки статуса:

<Steps>
  <Step title="Отправка запроса">
    POST запрос на `/api/v1/media` возвращает `id` генерации.
  </Step>
  <Step title="Проверка статуса">
    GET запрос на `/api/v1/media/{id}` возвращает текущий статус.
  </Step>
  <Step title="Получение результата">
    Когда статус `completed`, в ответе будут URL аудиофайла, обложка, название и длительность мэшапа.
  </Step>
</Steps>
