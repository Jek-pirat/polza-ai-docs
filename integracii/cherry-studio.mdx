Cherry Studio — десктопное приложение для работы с ИИ-моделями. Подключите Polza.ai как провайдера и используйте доступные в аккаунте модели в чатах.

## Требования

- Установленная [Cherry Studio](https://cherryai.com/)
- Аккаунт [Polza.ai](https://polza.ai/dashboard) и API-ключ

## Установка

1. Скачайте Cherry Studio с [официального сайта](https://cherryai.com/) и установите приложение.

<Frame>
  <img src="https://storage.yandexcloud.net/polza-docs/polza-docs/images/f034588a8c65ab33d12babf50b6b722c49d97da980b2315d9c65f94869624fbe.png" alt="Главное окно Cherry Studio" />
</Frame>

## Настройка провайдера Polza.ai

1. Откройте настройки приложения, нажав на значок шестерёнки в правом нижнем углу.
2. Перейдите в раздел **Model Provider**.

<Frame>
  <img src="https://storage.yandexcloud.net/polza-docs/polza-docs/images/1182d12eada3a8ae8dd43f017dcca6fa2341b27345190ecc5d6a2fd88e88247d.png" alt="Раздел Model Provider в настройках Cherry Studio" />
</Frame>

3. Нажмите **Add Provider**.

<Frame>
  <img src="https://storage.yandexcloud.net/polza-docs/polza-docs/images/a1f3aab287ec8cfa874b4e33c6fd18408fbd728577f243af885d7db7c1e5e12a.png" alt="Добавление нового провайдера в Cherry Studio" />
</Frame>

4. Заполните настройки провайдера:
   - **Название:** `Polza.ai`
   - **API Key:** ваш API-ключ Polza.ai из [личного кабинета](https://polza.ai/dashboard/api-keys)
   - **OpenAI API URL:** `https://polza.ai/api/v1`
   - **Anthropic API URL:** `https://polza.ai/api/`
5. Нажмите **Add**.

<Warning>
  Не публикуйте API-ключ и не отправляйте его в открытые чаты. Если ключ попал в общий доступ, отзовите его в личном кабинете и создайте новый.
</Warning>

## Выбор моделей

1. Отметьте модели, которыми хотите пользоваться.
2. Нажмите **Add selected models**.

  <img src="https://storage.yandexcloud.net/polza-docs/polza-docs/images/c24e2721512259589b039ec0f8ec451ffee42cac5fe1df5ce49cc1a59464c6ce.png" alt="Выбор моделей Polza.ai для добавления в Cherry Studio" />
</Frame>

## Запуск API Gateway

Откройте в настройках раздел **API Gateway** и нажмите **Start**.

<Frame>
  <img src="https://storage.yandexcloud.net/polza-docs/polza-docs/images/de3d29ce59931f1c2de38b70a449e7610a0c66825c377a38bc16d3856f1c6f31.png" alt="Раздел API Gateway с кнопкой Start" />
</Frame>

1. Откройте любой чат и выберите добавленную модель.

2. Отправьте тестовый запрос и убедитесь, что получили ответ.

  <img src="https://storage.yandexcloud.net/polza-docs/polza-docs/images/65e637f596909876d7215a569ea5c95aba484f8be025926dd5633a460aa8f8f0.png" alt="Успешный ответ модели в Cherry Studio" />

## Рекомендуемые модели

Polza.ai поддерживает сотни моделей; ниже подборка для типовых задач в Hermes Desktop. Полный — на [polza.ai/models](https://polza.ai/models).

| Модель | ID | Для чего подходит |
|---|---|---|
| DeepSeek V4.1 Flash | `deepseek/deepseek-v4.1-flash` | Самая экономичная, хороша для теста подключения и рутинных правок |
| Claude Sonnet 5 | `anthropic/claude-sonnet-5` | Фронтир Sonnet-класса: кодинг, агенты, профессиональные задачи |
| Claude Opus 5.5 | `anthropic/claude-opus-5.5` | Сложные рассуждения, многошаговые изменения в больших кодобазах |
| GPT-6 Sol | `openai/gpt-6-sol` | Средний ярус GPT-6: баланс скорости и качества для повседневных задач |
| GPT-6 Astra | `openai/gpt-6-astra` | Флагман OpenAI: продвинутая аналитика, deep research, длинные end-to-end |
| Gemini 3.8 Flash | `google/gemini-3.8-flash` | Быстрая и дешёвая, мультимодальная (текст/картинки/видео/аудио) |


## Решение проблем

<AccordionGroup>
  <Accordion title="Запрос не проходит">
    Проверьте, что API-ключ введён без пробелов, выбран добавленный провайдер, а endpoint указан без опечаток. Убедитесь, что API Gateway запущен, если используете его.
  </Accordion>
  <Accordion title="Модель отсутствует в списке">
    Вернитесь в настройки провайдера и добавьте нужную модель через **Add selected models**.
  </Accordion>
</AccordionGroup>
