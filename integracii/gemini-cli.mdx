Gemini CLI — официальный инструмент командной строки от Google для работы с AI-моделями прямо в терминале. Поддерживает агентные задачи, работу с кодом и файловой системой. Через Polza.ai вы можете использовать Gemini CLI не только с моделями Google, но и с Claude, GPT, DeepSeek и другими.

## Требования

- Node.js 18 или выше
- npm
- API-ключ Polza.ai ([получить в дашборде](https://polza.ai/dashboard/api-keys))

## Установка

<Steps>

<Step title="Установите Gemini CLI">

```bash
npm install -g @google/gemini-cli
```

Проверьте установку:

```bash
gemini --version
```

</Step>

<Step title="Задайте переменные окружения">

Укажите Polza.ai как бэкенд через переменные окружения:

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    export GOOGLE_GEMINI_BASE_URL="https://api.polza.ai/"
    export GEMINI_API_KEY="ваш_ключ_polza_ai"
    ```

    Чтобы не вводить каждый раз, добавьте в `~/.bashrc` или `~/.zshrc`:

    ```bash
    echo 'export GOOGLE_GEMINI_BASE_URL="https://api.polza.ai/"' >> ~/.zshrc
    echo 'export GEMINI_API_KEY="ваш_ключ_polza_ai"' >> ~/.zshrc
    source ~/.zshrc
    ```
  </Tab>
  <Tab title="Windows (PowerShell)">
    ```powershell
    $env:GOOGLE_GEMINI_BASE_URL = "https://api.polza.ai/"
    $env:GEMINI_API_KEY = "ваш_ключ_polza_ai"
    ```

    Для постоянного сохранения:

    ```powershell
    [System.Environment]::SetEnvironmentVariable("GOOGLE_GEMINI_BASE_URL", "https://api.polza.ai/", "User")
    [System.Environment]::SetEnvironmentVariable("GEMINI_API_KEY", "ваш_ключ_polza_ai", "User")
    ```
  </Tab>
  <Tab title="Windows (cmd.exe)">
    ```cmd
    set GOOGLE_GEMINI_BASE_URL=https://api.polza.ai/
    set GEMINI_API_KEY=ваш_ключ_polza_ai
    ```
  </Tab>
</Tabs>

**Опционально:** задайте модель по умолчанию через переменную окружения `GEMINI_MODEL`, либо выберите её при запуске флагом `--model`:

```bash
set GEMINI_MODEL=anthropic/claude-sonnet-5
gemini --model anthropic/claude-sonnet-5
```

</Step>

<Step title="Запустите Gemini CLI">

```bash
gemini
```

При первом запуске выберите способ авторизации — укажите **API Key** и введите ваш ключ Polza.ai.

## Возможности

- **Агентный режим** — Gemini CLI автономно выполняет многошаговые задачи: читает файлы, пишет код, запускает команды
- **Работа с кодовой базой** — анализирует весь проект, предлагает рефакторинг, пишет тесты
- **Поддержка MCP** — подключайте внешние инструменты через Model Context Protocol
- **Потоковый вывод** — ответы отображаются в реальном времени
- **Мультимодальность** — передавайте изображения и PDF прямо в запросе

## Решение проблем

<AccordionGroup>
  <Accordion title="Ошибка аутентификации (401 Unauthorized)">
    Проверьте, что переменная `GEMINI_API_KEY` задана правильно:
    ```bash
    echo $GEMINI_API_KEY
    ```
    Если пусто — повторите шаг с экспортом или перезапустите терминал.
  </Accordion>

  <Accordion title="Модель не найдена">
    Проверьте точное написание ID модели на [polza.ai/models](https://polza.ai/models). Gemini CLI передаёт ID модели как есть — опечатки приведут к ошибке.
  </Accordion>

  <Accordion title="Переменные не сохраняются после перезапуска терминала">
    На macOS/Linux добавьте строки `export` в профиль оболочки (`~/.zshrc`, `~/.bashrc`).
    На Windows используйте `[System.Environment]::SetEnvironmentVariable` с параметром `"User"`.
  </Accordion>
</AccordionGroup>
